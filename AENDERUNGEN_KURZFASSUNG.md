# Änderungen gegenüber der ersten Version

- Aufgabenbank von **124 auf 61** Übungsaufgaben reduziert; **12 Testfragen** unverändert.
- Definitionsthemen jeweils nur etwa **5 Aufgaben**, komplexe Form- und Fallthemen mehr.
- Wiederholte Originalaufgaben didaktisch zusammengefasst. Das Paket `ur-fallpaket` bündelt sechs Originalfälle zum Vertragsschluss.
- **Alle Übungen eines Unterkapitels sowie alle Testfragen stehen untereinander**. Keine Einzelaufgaben-Navigation mehr.
- Bei Antwortauswahl, Prüfung und Lösungseinblendung wird die Position in der Aufgabenliste möglichst gehalten.
- Fehler behoben: Bei einer noch nicht bearbeiteten Single-Choice-Frage war die erste Option visuell vorausgewählt.
- Avatar, XP, Lehrerzugang, Netlify Functions und Blobs, PDF-Portfolio sowie alle zentralen rechtlichen Korrekturen bleiben erhalten.
- `npm run check:all` prüft Aufgabenbank und die Darstellung aller Aufgaben im Übungsstapel.

**Hinweis:** Die Datei `KORREKTUREN_UND_ABDECKUNG.md` beschreibt, welche Originalfragen und Fallbeispiele in der gekürzten Version eigenständig, zusammengefasst oder nur im Theorie-Teil vorkommen.
